# okoflow Homebrew tap

Homebrew casks for the apps from [okoflow](https://github.com/okoflow).

```sh
brew install --cask okoflow/tap/waft
```

| Cask | App |
| --- | --- |
| `waft` | [Waft](https://github.com/okoflow/waft), on-device dictation for macOS with AI cleanup |

Each app's release script writes its cask; change the template in the app's repository, not here.
